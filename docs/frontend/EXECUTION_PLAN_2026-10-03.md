# 목표와 범위

사용자가 선호하는 현재 Codex 앱의 차분한 서체, 프로젝트·대화 중심 탐색, 읽기 쉬운 본문과 고정 입력창을 SSAK-AI에 적용한다. 코어 설계, PIN 인증, 서버 대화 리비전, 모델 선택 영속화, 프로젝트 식별자와 실제 상태 데이터의 의미는 유지한다. 현재 폴더의 작업 내용을 기준으로 하며 기존 변경을 되돌리지 않는다.

- 리더: DESIGN.md, 공통 SVG 아이콘, 디자인 토큰/CSS, 참고 근거·검증 기록, 빌드·최종 브라우저 검증.

# 참고 범위

공개 openai/codex는 CLI/Rust TUI와 app-server 소스이다. Desktop React UI 원본으로 표기하지 않는다. 참고 커밋: `604061ce51d194a3aa6aad3b3170240d096e1725` (2026-10-03). 설치 앱의 읽기 전용 자원 조사에서 공유 OpenAI Sans 및 시스템 폴백은 확인했으나 Desktop 전체 레이아웃 토큰은 확인되지 않았다. 독점 폰트 파일이나 앱 번들을 복사하지 않고, SSAK-AI에 적합한 시스템 서체와 재사용 가능한 토큰으로 구현한다.

검증 산출물: `docs/qa/2026-10-03-codex-ui/`.

# 구현 검증 기록

- 2026-10-03: 전체 프론트엔드 101개 파일·980개 테스트 통과. `tsc -b`와 production build 통과. 좁은 화면의 탐색·이력·검사 모달에서 명령 검색/단축키 도움말로 포커스를 넘기는 경계를 회귀 검증했다.
- 초기 프로젝트 ID가 늦게 도착하는 저장 이력 복원 경계를 ChatPage에서 한 번 재시도하며, 사용자가 이미 작성 중이면 덮어쓰지 않는다. 실제 브라우저에서 기존 대화 복원을 확인했다.
- 모바일 도구 행의 불필요한 분리를 줄였고, 셸을 명시적인 세로 flex로 구성하여 입력창의 화면 하단 배치를 수정했다.

- 최종 수정본: 103개 파일·1001개 테스트, TypeScript 및 production build 통과. 도움말 포커스·모달 전환과 비대화 경로 이력 복원 행동 테스트를 추가했다.
- 17개 경로를 375/768/1280에서 캡처하고 27개 상태와 설정 설명 3개를 더해 81개 현재 빌드 화면을 확보했다. 가로 넘침 0, 저장 대화 복원과 실제 27.3B 응답·복사를 확인했다. 최종 독립 QA/두 시각/맥락 검토가 모두 통과했다.

- 최종 대화 선택 버그: Sidebar에서 선택 직후 저장한 뒤 ChatPage로 이동하도록 수리했다. 실제 화면에서 비대화 3경로의 한 번 클릭 선택을 확인하고, 실제 ChatPage 마운트 회귀 테스트 RED/GREEN과 1001개 전체 테스트를 보존했다. 현재 81개 프레임 소스 SHA f8d138c7로 최종 독립 검토가 모두 통과했다.

- 인수 완료: 독립 Code/Security/QA/Context/Goal·VisualA/VisualB와 root런타임 감사 PASS를 현재 HEAD+소스SHA로 REVIEW_LEDGER에 기록했다. REPORT/INDEPENDENT_REVIEW/VISUAL_QA에 실행 결과와 기존 한계를 정리하고 실제 사용자 탭의 viewport를 원래 크기로 복원했다.
