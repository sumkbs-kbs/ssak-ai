# 진행 방식

주 에이전트가 실행 중인 SSAK-AI에 직접 질문한다. 질문·모델·맥락·도구 허용 상태·실제 답변·판정·실행 근거를 함께 기록한다. 실패는 재현한 뒤 앱 결함/모델 한계/환경 문제를 구분하고, 앱 결함은 실패 테스트→최소 수정→같은 질문 재검증으로 닫는다. 기존 Constitution과 Brain/Body 책임, 사용자 데이터·인증·27B 모델 선택을 유지한다.

현재 일반 대화는 `/v1/chat/completions`의 orchestrator/tool loop 경로를 사용한다. 별도 cognitive core의 SHADOW/ACTIVE 및 전용 surface를 일반 대화의 검증과 혼동하지 않는다. 전역 ACTIVE 전환, 자동 학습 승격 또는 운영 권한 변경은 시험을 통과시키는 수단으로 사용하지 않는다.

## 이번 실행 단계

| 단계 | 상태 | 인수 조건 |
|---|---|---|
| 현재 경로·기준·질문 매트릭스 확정 | completed | 최신 코드를 따른 호출 경로, 기능별 객관적 판정, 전용 대화와 실행 기록 |
| 주 에이전트의 최초 실제 질문·답변 검증 | completed | Q00/Q01/Q02/Q04 실행, 검색 금지 우회·리비전 충돌·출력 혼합·정정 누락 재현 |
| 재현한 앱 결함 수정 및 같은 질문과 추가 기능 재검증 | completed | 지시 보존·리비전·권한·출력 채널·공백 결함 red→green, 실제 재질문, Python 425개·프런트엔드 202개 통과 |
| 독립 수정 검토·결과와 후속 큐 갱신 | completed | 41개 파일 해시를 기준으로 코드 CLEAR/APPROVE, 새 화면 A/B PASS, 결과·실행 감사·정리 기록과 미검증 후속 큐 확정 |

## 항목별 운영 체크리스트

이번 회차에서 직접 실행한 항목만 판정을 갱신한다. 테스트 통과를 실제 응답 통과로 자동 승계하지 않는다. 아래의 부분 검증은 해당 영역 전체의 완료를 뜻하지 않는다.

| 영역 | 직접 확인할 동작 | 상태 |
|---|---|---|
| 기본 지시 | 지정 문장만, 한국어 간결성 | Q00 통과. 자연어 도구 금지 전반의 준수는 별도 검증 필요 |
| 추론 | 수치 정답, 조건·예외 검토, 잘못된 전제 정정 | Q01 할인·배송 계산 통과. 추론 유형 전반은 미검증 |
| 출력 계약 | JSON만, Markdown·코드·최종 답변과 진행 표시 구분 | Q01 JSON, Q13 300줄, Q15 제목·목록·코드 통과. 표는 미검증 |
| 불확실성 | 알려주지 않은 사실을 추정하지 않고 한계 명시 | Q03 `확인 불가`만 출력 통과 |
| 문맥 | 다중 턴 유지, 사용자 정정 우선, 다른 대화 격리 | Q04 정정, Q14 재조회 통과. 긴 문맥·다른 대화 격리 미검증 |
| 도구 | 실제 파일 읽기·없는 파일 오류·읽기 전용 정책 | Q07 필드와 읽기 기록 확인, 당시 코드 펜스 오류. Q08 오류와 실행 기록 통과. 쓰기·검색 별도 검증 |
| 검색 | 공식 출처·인용·본문 검증·실패 시 한계 | Q09 이번 회차 미실행 |
| 작업 상태 | 완료/실패/취소·history revision·재연결 상태 | 중단 후 새 요청·이력 재조회 통과. 재연결 경계 회귀 통과, 실제 연결 단절은 미검증 |
| 코어 전용 경로 | cognitive mode·전용 surface·실제 참여 | 경로 구분 완료. CLI off와 인증 없는 API 401만 관찰, 전용 실제 추론 미검증 |

## 다음 회차의 실행 큐

다음 항목은 이번 회차의 완료 단계와 구분한 후속 작업이다. 각 항목은 주 에이전트의 실제 질문 → 답변 및 도구 기록 검토 → 실패 재현 → 최소 수정 → 같은 질문 재검증으로 진행한다.

1. 짧은 지정 답변에도 수행되는 품질 재시도와 지연을 검토한다. 정확한 출력 계약을 유지하며 불필요한 재작성 여부를 실제 질문으로 판정한다.
2. Q09 공식 웹 검색과 선택한 페이지 읽기를 실행해 출처·시간·인용·실패 한계를 확인한다.
3. 별도 cognitive 경로의 실제 mode와 인증된 실행 surface를 확인한 뒤 그 경로에 직접 질문한다. `/health`의 `cov_active` 값을 cognitive ACTIVE의 증거로 사용하지 않는다.
4. 긴 문맥, 대화 간 격리, MAX 선택기의 `prompt[:500]` 보조 정보 영향과 원문 보존을 검증한다.
5. 승인 대기→사용자 결정→재개, 실제 연결 단절→재연결, 쓰기 허용 기능을 별도 시험한다. 이번 읽기 전용 시험의 결과를 승계하지 않는다.

질문 원문과 각 판정 근거는 `docs/qa/2026-10-03-core-live/QUESTIONS.md`와 `RESULTS.md`에 기록한다.

영구 QA 근거는 `docs/qa/2026-10-03-core-live/`에 둔다. 단기 진단 파일은 임시 debug journal에 등록하고 제거한다. 각 회차 종료 시 실제로 시험한 항목만 판정을 갱신한다.
