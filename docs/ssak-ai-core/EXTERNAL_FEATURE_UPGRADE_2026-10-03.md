# 범위와 방침

현재 작업 폴더의 최신 코드를 기준으로 Paperclip, Hindsight, Anthropic financial-services, VoiceStudio를 비교한다. 기존 Constitution, Brain/Body 책임, Files-first·Git-first, 인증·사용자 데이터·27B 모델 선택을 유지한다. 외부 제품 전체 설치보다 현재 실행 경로에 필요한 메커니즘을 최소한으로 반영한다. 외부 코드와 모델의 라이선스는 분리해서 검토한다.

VoiceStudio 앱 코드는 AGPL-3.0-only이며 모델에는 별도 조건이 있다. 이번 반영은 외부 코드를 복사하지 않고 표준 라이브러리와 기존 SSAK-AI 계층으로 필요한 입력 계약을 독립 구현한다. 외부 서비스, 유료 금융 커넥터, 음성 복제 모델을 자동 활성화하지 않는다.

## 구현 판정 기준

- 이미 존재하는 CAS·메모리 범위·음성 경로를 재사용한다. 사용되지 않는 어댑터를 추가해서 완료로 표시하지 않는다.
- 동시 요청은 작업 실행자를 한 명만 선택해야 하며, 점유 실패를 완료나 실행 성공으로 처리하지 않는다.
- 회상은 중복 자료가 예산을 점유하지 않도록 하고, 최신 정정과 명시적 사실 우선순위를 보존한다. 큰 자료 하나가 뒤의 유효한 작은 자료를 모두 막지 않아야 한다.
- 금융 숫자는 통화·규모·기준일·출처를 구분한다. 미확인 정보를 현재 사실로 만들거나 계산 가정을 숨기지 않는다.
- 음성 입력은 실제 허용 형식·크기·컨테이너를 확인한다. 손상된 오디오를 모델이나 외부 명령에 전달하지 않는다.
- 기존 변경을 되돌리거나 스테이징·커밋하지 않는다. 테스트는 임시 홈과 임시 저장소를 사용해 실제 사용자 자료를 변경하지 않는다.

## 구현 책임과 체크리스트

| 담당 | 실제 연결 지점 | 이번 인수 조건 |
|---|---|---|
| 작업 점유 담당 | BackgroundTaskRunner → TaskStateStore CAS | 두 실행자가 같은 task를 경합해도 orchestrator 실행은 한 번. 실패한 점유가 승자의 상태·결과를 바꾸지 않음 |
| 회상 담당 | MemoryManager.prefetch_all | 기존 provider/정정 우선순위 유지, 중복 자료와 지나치게 큰 선택 자료가 유효한 다른 자료의 예산을 막지 않음 |
| 금융 숫자 담당 | DataExtractor → `/api/search/extract` | 부호·소수·한국어 규모·통화·퍼센트/퍼센트포인트를 구분하고 숫자·단위·원문 출처를 실제 API까지 전달 |
| 음성 입력 담당 | `/api/voice/*` → VoiceService | 제한된 업로드 읽기, 빈/초과/손상 WAV 입력을 추론 전에 거절, 유효 오디오와 기존 형식 계약 유지 |

주 에이전트는 통합 판정·독립 검토·직접 실행 검증과 최종 문서를 맡는다. 다른 담당자는 소유 범위 밖의 파일·서버·브라우저·모델을 변경하지 않는다.

독립 검토에서 발견한 경계도 이번 구현의 인수 조건에 포함한다. 회상 예산은 충돌 해결 뒤 제목·출처를 포함한 최종 문자열에 적용한다. 금융 API는 `2**53`을 넘는 금액을 반올림하지 않고 정확한 십진 값을 보존하며, 복합 규모의 부호와 통화·기본 단위가 일치해야 한다. WAV는 유효한 PCM과 IEEE float 입력을 구분해 수용하고, 중복 format chunk와 개별 data chunk의 불완전 frame을 추론 전에 거절한다. 수정 전 실패 근거와 최종 통과 근거는 분리해서 보존한다.

영구 분석·수정·검증 근거는 `docs/qa/2026-10-03-external-feature-upgrade/`에 둔다. 다음 회차 후보는 이번 실행 단계와 분리한다.

실행 표면 검증에서 일반 요청에 포함된 `기능`이라는 단어가 자기 능력 보고서 분기로 잘못 들어가는 기존 문제가 발견되었다. 이 분류 조건과 행동 회귀를 좁게 보완하고, 같은 요청을 실제 27B 모델 대화에서 다시 확인하는 것을 세 번째 단계의 인수 조건에 추가한다. 해당 담당자는 `self_capability.py`와 그 테스트만 소유하며, 기본 코어 방침이나 모델 선택을 변경하지 않는다.
