# IMP-07 관리 API purge 검증

등록된 A를 active project로 전환하고 실제 auth middleware, login, DELETE /api/memory scope=all, 실제 project runtime/durable callbacks를 사용한다. route/manager/runtime 해석을 대체하지 않는다. unauth DELETE1·login POST1·auth DELETE1, auth purge 재시도0. native Chroma·GraphML에 사전 계산한 3차원 fixture를 저장하며 모델·다운로드·socket0, lifespan OFF/ASGI 범위로 판정한다.

성공: HTTP200 및 A graph/graph-vector/project-vector 잔여0, B graph/vector 내용과 삭제 전후 저장 파일 SHA 동일, global GBrain 및 outside sentinel 불변. scope=all의 global JSON provider 삭제는 기존 계약대로 허용한다. 실패시 부분 삭제와 HTTP 원문을 보존하고 소스 수정 후 새 고유 attempt를 사용한다. 요청 반복으로 기존 결과를 덮지 않는다. 전체 IMP07 및 IMP09/GA 완료를 의미하지 않는다.

native probe는 새 프로세스로만 실행하고 60초 total·10초 cleanup, timeout시 소유 그룹 TERM/KILL·wait/reap 결과를 남긴다. child와 source manifest는 실행 전에 고정한다.
