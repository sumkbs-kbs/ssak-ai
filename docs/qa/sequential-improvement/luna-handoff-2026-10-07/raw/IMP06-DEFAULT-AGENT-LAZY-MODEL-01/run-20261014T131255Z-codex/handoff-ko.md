# 기본 에이전트의 모델 준비 검수

판정: DONE_SCOPED. 구현 커밋은 `0e49b627db4351c5aaf51abaa6465da3fcfdc8f5`이며 주 에이전트가 검수했습니다. 별도 독립 검수는 NOT_RUN입니다.

설치된 모델을 선택했지만 아직 로드하지 않은 첫 요청은 ToolLoop의 선행 검사에서 거부됐습니다. 기존 ModelManager.get 준비 경로를 재사용하도록 최소 수정했습니다. 이미 준비된 모델과 콤보의 기존 실행 경로를 유지하고, 준비 예외는 원래 예외로 전달하며 재시도하지 않습니다.

새 계약 7개는 수정 전 5 실패/2 통과였고 수정 후 모두 통과했습니다. 기존 영향 selector의 최종 원문 결과는 clean/root 각각 104 통과/2 실패입니다. 남은 두 실패는 기존 `/tmp/test` 경로 단언과 격리된 테스트 작업 경로의 차이였습니다. 해당 두 사례를 별도 사본에서 경로 리터럴만 바꿔 각각 2 통과로 확인했습니다. 원본 selector 전체가 106/106 통과했다고 판정하지 않습니다. 첫 후보의 100 통과/6 실패도 보존합니다. 최종 코드의 lint/format/types/메모리 compile은 clean/root 각각 종료 코드 0입니다.

ROOT의 기존 ToolLoop 변경을 preimage로 보존하고 역패치 바이트 동일성을 확인했습니다. 별도 소스 1,252개와 기존 staged diff는 불변입니다. 구현은 ToolLoop와 새 계약 테스트 두 파일에 한정됩니다.

실제 브라우저 revision-v3에서 이전의 미로드 거부가 해소돼 통제된 제공자 HTTP 503까지 도달했고 제품 SSE 오류와 입력 복구를 확인했습니다. 이는 실제 브라우저/제품/HTTP 경로이며 제공자 응답은 통제된 fixture입니다. 실제 신경망 품질을 검증하지 않았습니다. 당시 작업 큐의 별도 실패 및 guard 위반은 후속 글로벌 커서 검수에서 구분합니다.

task-only.patch와 재구성, 검사 원문/영수증, JUnit 및 경로 사본의 바인딩을 함께 보존합니다. 과거 원장 NOT_RECOVERED 및 전체 IMP-09 PARTIAL은 유지합니다.
