# 대시보드 게이트 서버 소유권 수정

접근성 required 게이트가 서버를 직접 기동하고 명시된 접근성 스펙을 실행하도록 기존 ambient wrapper를 재사용했습니다. 선택한 스펙의 exit code와 cleanup을 검증하고, 기존 ambient·disclosure·hub 단계는 기본 경로에 유지했습니다. required 23개, 실패 단언, axe 기준과 grep 선택 범위를 낮추지 않았습니다.

정적 계약 24개 및 Ruff·format·오류 수준 타입 검사 통과. 초기 format 실패와 수정 원문은 별도 시도 폴더에 보존했습니다. 세 파일 patch 재구성이 byte-identical입니다.

실제 브라우저 첫 실행은 접근성 33/2, witnesses 18/12, ambient 11/5(통과/실패)입니다. 실패는 글자 대비 및 현재 화면과 어긋난 탐색·표시 계약입니다. 원문을 보존했고 후속 UI 수리에서 다룹니다. 이 패키지 자체를 제품 게이트 전체 PASS로 판단하지 않습니다. 격리 인증·스토리지와 비수신 모델 endpoint를 사용했고, 모델 추론 성공을 주장하지 않습니다. 독립 검수와 새 후보 전체 게이트는 대기 상태입니다.
