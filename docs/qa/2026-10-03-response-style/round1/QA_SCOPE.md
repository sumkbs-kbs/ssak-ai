# 응답 스타일 검증 범위

사용자 요청: 답변 출력의 글꼴·스타일을 현재 Codex와 어울리도록 정리. 기존 앱 전체 화면 개선 완료 기록은 별도 유지하며 이번 검증은 응답 DOM/Markdown/CSS 변화에 한정한다. 저장 데이터, API, 모델 설정, PIN 인증은 변경하지 않는다.

## 화면 목록

375/768/1280 × 954px에서 다음 여섯 상태를 모두 새로 캡처한다.

1. 기존 저장된 인사 응답, 응답 정보 닫힘.
2. 같은 응답의 응답 정보 열림.
3. 같은 응답의 원문 보기 열림.
4. 실제 새 모델 응답의 제목·본문·목록·인라인 코드 위치.
5. 같은 응답의 언어 지정/미지정 코드 및 표 위치.
6. 같은 응답의 인용문·링크·응답 정보 끝부분.

총 18개 수정 후 상태와 기본 창 크기 최종 산출물 1개. 추가 스트리밍/복사/키보드 상태는 별도 증거로 기록한다. 수정 전 같은 인사 응답의 375/768/1280 원본 3개와 같은 크기 수정 후 이미지는 변화 비교 기준이며 Codex Desktop의 정확한 픽셀 정답은 아니다.

모든 실제 이미지는 정상 확장자와 크기를 확인하고 원본 해상도로 검토한다. PNG 비교용 변환은 동일 RGB 픽셀의 형식 변환만 허용한다. 라이브 상태 스트립의 시간 변화는 실제 변화로 기록하며 유사도 수치를 디자인 품질 점수로 사용하지 않는다.

## 기능 경계

- 기존 원문 및 대화 선택/모델 유지, 정상 실제 응답 완료.
- 본문 복사에서 인식된 시스템 장식만 제외; Markdown·일반 이모지 보존.
- 언어 없는 코드도 코드 블록으로 표시하고 정확한 코드 텍스트 복사.
- 응답 정보/원문 네이티브 접기, 키보드 토글, 읽기 가능한 폰트 및 포커스.
- 좁은 화면 전체 가로 넘침 없음; 긴 코드/표의 내부 스크롤 허용.
- 인용·들여쓰기·펜스·인라인 코드·사용자 입력은 장식 추출에서 보존.
- 승인·오류·아티팩트·Markdown 정화·Mermaid/Carousel 기존 경로 회귀 검증.

경계 기능은 의미 있는 기존/추가 테스트를 함께 실행한다. 실제 브라우저에서 고의적인 503/CAS/승인 요청을 만들어 인증이나 코어 상태를 변경하지 않는다. 운영 페이지 전체, 실제 OS IME, Electron 네이티브 접근성, Lighthouse/전체 axe 검사는 이번 응답 스타일 완료 주장의 범위에 넣지 않는다.

## 독립 검토

최종 코드 및 캡처를 동결한 뒤 새 읽기 전용 검토자 둘이 모든 열거된 원본 및 비교 PNG와 모든 diff hotspot을 확인한다. 이전 작업의 PASS는 이번 변경의 승인으로 재사용하지 않는다.
