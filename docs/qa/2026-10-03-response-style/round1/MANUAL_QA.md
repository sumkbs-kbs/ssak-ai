# 실제 브라우저 검증

최종 소스/배포 빌드 후 동일한 http://127.0.0.1:8000/chat 잠금 해제 탭에서 검증했다. PIN·저장소·API 숨은 호출은 사용하지 않았다.

- 기존 인사 응답: 375/768/1280 × 954에서 본문/정보 열림/원문 열림 9개. 768에서 Enter 및 Space로 네이티브 summary 토글과 포커스 확인.
- 새 실제 모델 응답: qwen3.8:latest (27.3B), 입력143/출력184토큰. Working 시작/27초 중간 상태 후 생성 완료 및 전송 버튼 복원. 응답 중 503나 콘솔 warn/error는 관측하지 않음.
- 새 응답의 제목·본문·목록/코드·표/인용·링크 위치를 같은 3폭에서 각각 캡처(9개). 본문16px/1.7, 제목18px, 코드13px, 표14px. 모든 기본 문서 폭이 뷰포트와 동일하고 긴 코드는 pre 내부 스크롤. 전체 페이지 가로 넘침 없음.
- 응답 본문, ts 코드, 언어 없는 코드의 실제 복사 버튼을 누른 뒤 빈 미전송 입력창에서 Meta+V로 붙여넣음. DOM 입력값과 기대값이 일치. 입력은 검사 직후 비웠으며 전송하지 않았다(COPY_RESULTS.json). 도구 clipboard.readText는 이전 캐시값을 돌려주므로 복사 판정에 사용하지 않았다.
- 링크는 https://openai.com, target=_blank 및 rel=noopener noreferrer. 외부 링크 이동은 하지 않음.
- 원문은 React 평문 pre로 보존되며 중첩 접기 영역에 표시. 기존7개 대화 모두 남고 검증 대화1개 추가(HISTORY_PRESERVATION.json). 모델/빈 입력 유지 및 기본757px 창 크기 복원.

## 실제 응답의 생성 내용

모델이 도구 금지 요청에도 write_artifact를 사용해 로컬 artifacts/답변_스타일.md를 만들고 그 작업 로그를 응답에 포함했다. 도구 실패/승인/작업 정보는 숨기지 않는 기존 계약에 따라 보존했다. 생성된 원문에는 첫 번째 목록 앞의 줄바꿈이 없어 그 항목이 본문 끝에 이어지며, 실제 두 번째 항목은 목록으로 렌더링된다. REAL_RESPONSE.txt로 확인한 모델 생성 원문이며 프론트에서 문구나 줄바꿈을 만들어 수정하지 않았다. 이번 요청은 응답 스타일이고 모델의 도구 지시 준수는 변경 범위에 포함하지 않는다.

## 한계

실제 응답에서 추가 승인/503/CAS/OS IME는 유도하지 않았고 기존 테스트로 회귀 경계를 확인했다. 전체 운영 페이지, Lighthouse/axe, Electron 네이티브 접근성을 검증한 주장이 아니다. macOS 시스템 글꼴과 한국어 fallback을 쓰며 Codex Desktop의 비공개 글꼴 또는 정확한 픽셀 복제를 주장하지 않는다.
