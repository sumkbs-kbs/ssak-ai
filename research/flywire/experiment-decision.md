## A. 희소 기억 검색 — INCONCLUSIVE / 구조 주장 REJECTED

**가설.** 같은 임베딩·같은 예산에서 확장(expansion)+승자독식(kWTA) 코드가 정확 cosine 베이스라인의
품질을 유지하면서 지연·메모리를 줄인다. 그리고 **연결망에서 온 좌표 사상**이 무작위 사상보다 낫다.

**베이스라인.** `dense_exact` — 512차원 fixture 해시 임베딩의 정확 cosine.
recall@10 **0.7722** · nDCG@10 **0.6889** · warm p95 **1.47ms** · index 195,584 nnz · 할당 피크 **6.32MB**.

**측정.** task 24 가 봉인한 검색셋(382 문서 · 100 질의 · 그중 holdout **30**) · 사이트 분리 split
(`fc0c2963…`) · seed 3 · k=10 · 질의별 짝지은 부트스트랩 CI(표본 단위는 **질의**).

**결과 — 희소성은 값을 한다.**

| 조건 | recall@10 | nDCG@10 | warm p95 | 판정 |
|---|---|---|---|---|
| `dense_exact` (베이스라인) | 0.7722 | 0.6889 | 1.47ms | — |
| `sparse_random@e4096@r0.05` | 0.7704 (−0.0019) | 0.6906 (+0.0017) | **0.166ms (88.7% 개선)** | INCONCLUSIVE |
| `sparse_random@e2048@r0.05` | 0.7648 (−0.0074) | 0.6794 (−0.0095) | 0.167ms | INCONCLUSIVE |
| `simhash` | 0.4111 (−0.3611) | 0.33 | 0.02ms | REJECTED |

`INCONCLUSIVE` 인 이유는 게이트가 아니라 **증거**다: 짝지은 recall 델타 CI 가
`[−0.0167, +0.0111]`(e4096@0.05)로, 허용 하락 −0.01 을 **하한이 넘는다**. 즉 "실질 하락이 없다"를
증명하지 못했다. holdout 질의 30개로는 −0.01 문턱을 CI 로 통과할 수 없다 — 더 큰 holdout 이 필요하다.

**결과 — 구조 주장은 기각된다.** mask 계열은 **전부**(12/12 구성) recall 하락 −0.094 … −0.189 로
기각됐고, 같은 예산의 무작위 사상(`sparse_random`)보다 **일관되게 나빴다**.
degree 보존 shuffle 대조군도 실제 mask 보다 나았다 — 즉 차이는 "생물학"이 아니라 **좌표 다양성**이다.

**실제 회로 mask (opt-in, KC_to_MBON · CONFIRMED · sha256 `13987e1600c3a3c4…` · 49,236 edge)**:
recall@10 **0.2500~0.2667** (−0.506~−0.522). 기계적 이유가 분명하다 — 이 회로의 **post 노드는 84개**뿐이라
2048/4096 좌표 코드가 서로 다른 문서를 분리하지 못한다(색인 nnz 도 6,785~7,075 로 붕괴).

**한계(정직).**
- 임베딩은 **fixture 해시 임베딩**이다. 실제 모델 임베딩 품질은 재지 않았다(`model_embedding=NOT_RUN`).
- 정확 cosine 만 품질 참조로 두었다. 프로젝트 ANN(chromadb) 팔은 이 실행에 없다(임베딩 모델 다운로드 필요).
- 관련도 라벨은 각 케이스 질의에 대한 것이고, 다른 질의에 대해서는 0 으로 셌다(pooled 평가의 한계).
- `index_peak_alloc_bytes` 는 tracemalloc 할당 피크이며 프로세스 RSS 가 아니다.
- mask 의 애초 대상은 **뉴런 활성**이지 문서 좌표가 아니다 — 여기서 잰 것은 사상의 공학적 대체일 뿐이며,
  "뇌 구조를 넣으면 좋아진다"는 주장의 근거가 되지 않는다. 이 실험은 그 주장을 **기각하는 쪽**의 증거다.

## B. 목표 중심 작업 기억 — ACCEPTED (상한·불변식) / REJECTED (점수)

**가설.** 제한된 문맥에서 목표 관련성 기반 선택이 필요한 증거를 더 적은 토큰으로 유지한다.

**조건.** `fifo_window`(상한 없음 = 현재 동작) · `pinned`(같은 상한) · `summary`(같은 상한, 출처 상실) ·
`selector`(같은 상한, 결정적 점수). fixture 8개 합성 시나리오(목표 변경·중단/재개·오래된 오답·악성 페이지·
동시 세션·예산 압박). 승격은 네 축 **모두**: 제약 누락 0 · 교차 세션 0 · 조용한 폐기 0 · 성공 하락 ≤1%p ·
토큰 ≥10% 감소.

| 조건 | 성공 | 토큰 | 제약 누락 | 교차 세션 | 조용한 폐기 | 출처 상실 |
|---|---|---|---|---|---|---|
| `fifo_window` | 1.000 | 83.5 | 0 | 0 | 0 | 0 |
| `pinned` | 1.000 | 48.6 | 0 | 0 | **20** | 0 |
| `summary` | **0.000** | 33.0 | 0 | 0 | 0 | **8** |
| `selector` | 1.000 | 49.1 | 0 | 0 | 0 | 0 |

**판정 세 방향.**
- `bounded_selection` (selector vs 현재 동작) → **ACCEPTED**: 토큰 **−41.2%**, 성공 동일, 불변식 4축 0.
- `goal_scoring` (selector vs pinned, 같은 상한) → **REJECTED**: 토큰 이득 없음(−1.0%). 같은 상한의 단순 핀이
  같은 성공을 같은 토큰으로 낸다 → **목표 점수 자체는 여기서 값을 못 했다**.
- `summary_quality` (summary vs selector) → **REJECTED**: 성공 하락 **100%p**(출처를 버린 요약은 사실로
  승격할 수 없으므로 필수 증거가 사라진다).

**채택되는 것.** 목표 점수가 아니라 **압축 상한 + 네 불변식(제약 불삭제 · 세션 격리 · 초과 보고/외부화 ·
악성 문장 격리)** 이다. `goal_scoring` 이 기각됐으므로 배포 기본값에 목표 점수를 넣을 근거는 없다
(제품 기본 설정 변경 금지 원칙과도 일치).

**한계(정직).**
- "성공"은 **결정적 커버리지 프록시**다(필수 증거 보존 + 출처 보존 + 악성 미승격). 모델이 낸 실제
  task success 는 재지 않았다(`model_success=NOT_RUN`) — 그래서 앞의 "성공 하락 ≤1%p" 는 모델 성능 하락이 아니다.
- fixture 8개는 합성이며, 상한은 "필수 + 잡음 25%" 로 구성된다 → **토큰 감소는 구조적**이다.
- 교차 세션은 fixture 안에서만 쟀다(실제 동시 세션 프로세스는 범위 밖).
- `fifo_window` 가 상한 없이 도는 것은 현재 동작의 재현이며, 그래서 토큰 비교는
  "압축하지 않음 vs 압축함"이다 — "같은 문맥에서 더 잘 고름"이 아니다.
